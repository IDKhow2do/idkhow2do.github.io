# 合并入口门户 · 架构说明

本地高保真静态预览：把选题站与视觉素材站的**只读交接快照**汇成一个入口。不触碰线上站点，不写回，不请求凭据。

## 信息架构

| 层级 | 内容 |
|------|------|
| 顶栏 Tabs | **选题**（主） / **视觉素材** |
| 选题 chips | 全部 · AI · 半导体 · 科技产品 · 社会生活 · 其他；可选「已赞」快捷滤 |
| 选题卡片 | 预览图或占位 · 标题 · 分类 · 证据/状态 · 赞/收藏指示 |
| 选题详情抽屉 | 描述、caveat、原文链接、来源；不展示内部 ID / 原始字段名 |
| 视觉卡片 | 预览 · 标题 · 分类 · **许可待核** · 来源链接（无下载按钮） |
| 视觉空/缺口态 | 站内约 113 条，本快照仅 1 条待核 → 提示重新导出后再刷新 |

## 数据层

- 源：`handoff-YYYY-MM-DD/` 只读快照；本预览把 JSON **复制**到 `portal/data/`（相对路径 `fetch`）。
- 加载：`news_topics.json`（`topics[]`）+ `news_feedback.json`（按 `url` 合并 liked/saved/notInterested）+ `visual_items.json`（`items[]`，可能 partial）+ `manifest.json`（日期与计数角标）。
- **刷新方式**：丢入新 handoff 目录后，覆盖 `portal/data/*.json`（或改 `app.js` 中 DATA 路径指向新目录），刷新页面即可。无构建、无服务端。

## 与两站的关系

- 本门户是 **aggregation shell**（聚合壳）：读导出，不重建线上应用，也不是迁移。
- 选题站 / 视觉站仍各自独立；线上写操作、凭据、媒体二进制均在交接包 `excluded` 之外，本预览亦不引入。

## 技术选型

- **静态 HTML / CSS / 原生 JS**，无构建步骤。
- 打开方式：`index.html` 经本地静态服务（推荐 `python3 -m http.server`）加载，以便 `fetch` JSON；`file://` 可能被浏览器拦截。
- 理由：一人预览、快照驱动、零依赖、可直接对照美学稿；后续若接只读导出 API，只需换 `loadData()` 数据源。

## 扩展点

1. 只读导出 API（替换本地 JSON）
2. 更多 Tabs（如待核队列、偏好摘要）
3. 偏好权重滤镜（读 `news_preferences.json`）
4. 详情抽屉增强（相关标签、跨站跳转说明）
5. 视觉库完整导出后补齐网格与逐项反馈

## 明确非目标

- 不请求 / 不存储凭据与 cookie
- 不向线上站点写回赞/收藏
- 不下载媒体文件（仅展示链接与元数据）
- 不伪装「可直接下载」的素材按钮
